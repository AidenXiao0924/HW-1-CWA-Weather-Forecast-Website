# Legacy presentation layer

Historical reference only. Not an alternative supported UI or deployment entrypoint.
backend.py, index.py and frontend/ were archived after Streamlit tests/startup/map verification.
They are not maintained against the current config/dependencies. Do not run them from this
folder or install their old dependencies in the current app. Restore the previous version
from GitHub history if the historical application is needed. VERCEL.md describes only that old version.
The only supported web command is: streamlit run streamlit_app.py
